# Contributing to Rent Truth BD 🤝

We welcome contributions from the Bangladeshi developer community to optimize our smart housing platform!

---

## 🛠️ Code Standards & Rules

- **Language**: Use Kotlin exclusively for Android sources.
- **UI Toolkit**: Jetpack Compose following Material Design 3 guidelines.
- **Asynchrony**: Leverage Coroutines and StateFlow to maintain responsive state management.
- **Localization**: Ensure all text labels can support localized translations in `res/values/strings.xml` to assist bilingual users.

---

## 📦 Pull Request Process

1. Fork the repository and formulate your feature branch: `git checkout -b feature/your-awesome-fix`.
2. Do not include hardcoded configuration profiles or credentials inside your commits.
3. Validate your code satisfies compile standards: `gradle compileDebugKotlin`.
4. Submit your pull request mapping specific issue threads or design tasks.
