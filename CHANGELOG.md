# Rent Truth BD — Changelog 📜

This document logs release versions, stable enhancements, and architectural upgrades implemented for the Rent Truth BD smart housing ecosystem.

---

## [2.1.0] - 2026-05-28
### Added
- **Landlord Operations Registry**: Permanent digital registries maintaining tenant status history, ownership credentials logs, and archived historical rental contracts.
- **Tenant KYC Identity Vault**: Expand NID verification with versioned uploads, document expiry monitors, and mobile-friendly file select simulations.
- **Broker Command Splitting System**: Broker partnership routing, residential vs corporate workspace splitters, and corporate rental support.
- **Subscription Upgrades Console**: Plan-matrix restrictions (Free, Premium Owners, Premium Brokers, Corporate plans) backed by manual mobile payments validations.
- **WebSocket RentSync Network Logs**: Simulator tracking packet latency heartbeats, optimistic queue dumps, and transaction safe database safeguards.

### Changed
- Aligned `metadata.json` layout with Android main package properties.
- Upgraded Admin Desk dashboards supporting complete user lookup tags search, direct overrides, document reviews, and platform infrastructure dials.

---

## [1.0.0] - 2026-04-12
### Added
- Primary platform launch on Kotlin Android platforms.
- Native SQLite Room models supporting core listings, roommate requests, roommate split models, and escrow safes.
- Gemini AI Room Advisor rest integrations.
